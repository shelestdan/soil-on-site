# Soil On Site

Custom editable WordPress theme for Soil On Site.

Edit site content in `Appearance -> Customize -> Soil On Site Content`.

Editable areas:

- Brand / SEO
- Hero
- When Needed / System Types
- Process
- What To Do Next
- Service Areas
- FAQ
- Contact / Form

The quote form sends through WordPress mail. If messages do not arrive, configure SMTP on the hosting account.
